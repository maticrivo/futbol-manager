installable on iPhone/iPad and Android, and push notifications are enabled from

## Full instructions

### iPhone / iPad

1. **Open the link in a real browser.** Safari is the simplest and most reliable choice.
   Do not use the browser built into WhatsApp, Instagram, or Facebook — if the link
   arrived in a chat, tap `···` and choose **Open in Safari**. (Since iOS 16.4, Chrome,
   Edge, and Firefox on iPhone also offer **Add to Home Screen** from their share menu.)
2. Tap the **Share** button (square with an arrow) in the toolbar.
3. Scroll down and tap **Add to Home Screen** (הוספה למסך הבית).
   On iOS 26 and newer, leave **Open as Web App** switched on, then tap **Add**.
   If it is switched off, the icon opens as a bookmark and notifications will not work.
4. Open **Tuesday Football** from the new icon on the home screen.
5. Sign in with Google or Facebook if prompted. New members also need admin approval.
6. Go to **Profile** (פרופיל) → **Push notifications** (התראות דחיפה) →
   **Enable notifications** (הפעלת התראות) → **Allow**.
7. In **Notification settings** (הגדרות התראות), tick the alerts you want and tap
   **Save settings** (שמירת הגדרות).

> Apple requires iOS/iPadOS **16.4 or newer**, and only allows web push for apps added
> to the home screen. In Safari tabs the app shows the install steps instead of the
> enable button — this is expected.

### Android

1. **Use Chrome** (or another full browser). If the link opened inside WhatsApp,
   Instagram, or Facebook, tap the menu and choose **Open in Chrome** / **Open in browser**.
2. Chrome may offer **Install app** in a banner. Otherwise open the menu `⋮` and tap
   **Install app** (התקנת אפליקציה) or **Add to Home screen** (הוספה למסך הבית) → **Install**.
   - Samsung Internet: `☰` → **Add page to** → **Home screen**.
3. Open **Tuesday Football** from the home-screen icon.
4. Sign in with Google or Facebook if prompted.
5. Go to **Profile** (פרופיל) → **Push notifications** (התראות דחיפה) →
   **Enable notifications** (הפעלת התראות) → **Allow**.
6. In **Notification settings** (הגדרות התראות), tick the alerts you want and tap
   **Save settings** (שמירת הגדרות).

> On Android notifications also work in the browser tab, but installing the app is
> recommended so it opens full-screen and stays signed in.

### Troubleshooting

| Problem | Fix |
| --- | --- |
| Link opened inside WhatsApp/Instagram and nothing can be installed | Open it in the real browser first: iOS → `···` → **Open in Safari**; Android → `⋮` → **Open in Chrome**. |
| No "Add to Home Screen" option on iPhone | Use Safari (or another full browser), not private browsing; needs iOS 16.4+. |
| Installed on iPhone, but notifications still unavailable | The icon was added as a bookmark: on iOS 26+, re-add it with **Open as Web App** on. On older versions the app must open without Safari's toolbar. |
| No "Enable notifications" button on iPhone | The app is not installed, or it was opened from a Safari tab. Open it from the home-screen icon. |
| Permission was denied by mistake | iPhone: **Settings → Notifications → Tuesday Football → Allow Notifications**. Android: long-press the app icon → **App info → Notifications**, or Chrome `⋮` → **Settings → Site settings → Notifications** → allow the site. Then reopen the app and tap **Enable notifications** again. |
| Enabled, but no notifications arrive | Check the alert categories are ticked and saved in **Notification settings**; disable battery restrictions for the app (Android: **App info → Battery → Unrestricted**); check Focus / Do Not Disturb. |
| Deleted the home-screen icon | Reinstall and enable notifications again — removing the icon unsubscribes the device (iOS). |

## Admin notes

- Web push requires HTTPS — the production URL already satisfies this.
- Each browser/device is a separate subscription. Members must enable notifications on
  every phone/tablet they use.
- The enable button is on **`/profile`**, below the **Notification settings** card.
- The iOS install hint is automatic (`PushSetup` detects iOS + non-standalone mode);
  nothing else needs configuring.
- If push does not arrive at all, check the `VAPID_*` and `NEXT_PUBLIC_VAPID_PUBLIC_KEY`
  variables and that the production build was created after they were set.
