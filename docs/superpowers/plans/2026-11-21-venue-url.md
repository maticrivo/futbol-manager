# Venue URL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optional `venueUrl` field to matches and render the venue name as a clickable external link opening in a new tab when set.

**Architecture:** We add a `venue_url` column to the Drizzle schema, generate a migration, update domain match types and actions (`updateMatchAction`), add a URL input field to the admin match edit form with translations, and update `MatchCard` to render the venue name as an external link (`target="_blank" rel="noopener noreferrer"`) when `venueUrl` is present.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Drizzle ORM, MySQL 8, next-intl, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-21-venue-url-design.md`

## Global Constraints

- Monetary amounts in integer agorot; time in `Asia/Jerusalem`.
- Hebrew RTL parity and trilingual support (`he`, `en`, `es`) required.
- No domain behavior, database schema, or action signature changes other than adding `venueUrl`.
- Minimum touch target size 44×44px on mobile.

## Review Focus

1. **Invalid URL input handling:** If an invalid URL or malformed string is entered into `venueUrl`, the action rejects it cleanly. (*Pinned to Task 2 in `tests/domain/matchEdits.test.ts`*).
2. **External link security:** When `venueUrl` is present, the rendered anchor tag includes `target="_blank" rel="noopener noreferrer"`. (*Pinned to Task 3 in `tests/unit/matchCard.test.ts`*).
3. **Empty/Null fallback:** When `venueUrl` is absent or empty, the venue renders as plain text. (*Pinned to Task 3 in `tests/unit/matchCard.test.ts`*).
4. **Trilingual translation coverage:** All new message keys (`admin.match.edit.venueUrl`, etc.) exist in `en`, `he`, and `es`. (*Pinned to Task 2 in `tests/domain/profilePage.test.ts` or message parity test*).
5. **Database column nullable behavior:** `venueUrl` is fully optional and defaults to null. (*Pinned to Task 1 in `tests/db/schema.test.ts`*).
